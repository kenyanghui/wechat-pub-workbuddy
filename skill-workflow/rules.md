# 硬性规则 — 违反必出事故

## 1. 结构分层（四层分离）

```
skill/
├── SKILL.md          # 入口：只写 What/When/路由表，≤150 行
├── SETUP.md          # 面向非技术用户的图文配置指南
├── config.json       # 个人配置唯一去处（向导生成）
├── _ledger.md        # 进化台账（运行时回写）
├── references/       # 给 agent 读的编排手册、提示词模板、API 速查
├── templates/        # 产物模板（topics/drafts/qa/queue + format 组件）
└── scripts/          # 全部确定性逻辑（shell/python，幂等可重跑）
```

- **SKILL.md 只做路由**：任务意图 → 指向 references/scripts 的表。改流程不改 SKILL.md。
- **提示词与代码分离**：子代理提示词模板放 `references/agent-prompts.md`，占位符全部从 config.json 填充，禁止硬编码用户参数。
- **API 踩坑速查单独成文**（如 ima-api-mechanics.md）：记录"哪些端点有效/无效/静默 no-op"，避免下次再实测一遍。

## 2. 安全红线

1. **不可逆操作物理隔离**：有发布/外发能力的步骤，脚本层面只实现到"草稿/预览"（如 post_draft.py 根本没有群发函数），不靠提示词约束。
2. **凭证只放 `~/.config/<服务>/`**，每文件一行纯文本，chmod 600；绝不进提示词、台账、日志、git。
3. **写操作必须带归属参数**（如 IMA 写入必带 folder_id），防数据落根目录难清理。
4. **Truth-first**：外部条件不足时允许降级减产并留痕，绝不编造数据凑流程。

## 3. 可靠性规则

1. **磁盘为准**：子代理返回后必须 Read 验证产物文件真实存在，不信口头回报；缺失则携失败原因补 spawn 一次（≤1 次）。
2. **断点续跑**：每轮产物目录带 `_status.json`，启动先盘点近 2 天，`finished!=true` 缺哪步补哪步，禁止覆盖已验证产物。
3. **降级路径**：每个外部依赖（API/凭证）都要定义"缺失时怎么办"——跳过、本地打包或明确报错，且降级要在结果简报里标注。
4. **日期/时间必须实测**（`date` 命令），不信任模型记忆里的"今天"。
5. **防漂移自检**：提供 `check_drift.sh`，校验配置字段、台账章节、脚本健康；版本升级后跑一遍。

## 4. 配置体验

1. **5 分钟上手**：setup_wizard.py 交互式向导（探测凭证→列资源供选→实测连通→生成配置和台账），别让用户手改 JSON。
2. **一键诊断**：diagnose.py 输出本机 IP、凭证状态、连通性，把"报错码→解法"写进 SKILL.md 故障速查表（如 40164=IP 白名单）。
3. **配置热改**：换库/改人设只改 config.json，不动技能任何其他文件。
